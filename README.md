# YouTube Downloader

A simple command-line tool to download YouTube videos and audio using yt-dlp.

## Requirements

- Python 3.8+
- Dependencies listed in `requirements.txt`

## Installation

```bash
git clone https://github.com/nono271105/youtube_download.git
cd youtube_download
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

```bash
python YTB_DWNL.py
```

Follow the prompts to enter a YouTube URL and choose your download format (video or audio).
